# OctaNet-Task-1

💪 Welcome to FitNest Gym Landing Page! 🏋️‍♀️
Hey there, fitness enthusiast or fellow developer! 👋
This is the official FitNest Gym Landing Page project — a clean, responsive, and stylish front-end design built with 💻 HTML & CSS to represent a premium gym website.

🌟 What’s Inside?
✨ Home Section – Eye-catching intro with motivational quote and a bold CTA.
📖 About Us – Learn what makes FitNest Gym special!
🔥 Features – Highlights like certified trainers, modern equipment & 24/7 access.
📝 Registration Form – Ready-to-use form to collect member details.

Each section is beautifully styled with custom backgrounds and a consistent golden-black theme 🖤✨.

📱 Fully Responsive
Whether you're on a phone 📱, tablet 💻, or desktop 🖥️, the design adjusts smoothly thanks to well-written media queries. Plus, there’s a slick mobile menu icon 🍔 ready for future interactivity!

🧰 Built With:
HTML5 ⚙️
CSS3 🎨
Remix Icons 🎯 (ri-menu-line for mobile nav)
